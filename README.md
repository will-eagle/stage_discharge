# Stage Discharge

## Overview
This is a python module to read and clean up sensor logs (HOBO, and InSitu), pull data from the HOBO Licor cloud, build stage/discharge rating curves from manual measurements, and predict discharge from the stage records.

Main submodules are
- read_write
- hobo_fetch
- build_stage
- rating_curve
